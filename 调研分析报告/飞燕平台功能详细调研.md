## 二、核心功能模块详解

### 2.1 产品管理

| 功能项 | 详细说明 |
|-------|---------|
| **项目创建** | 支持多项目管理，每个项目独立资源隔离 |
| **产品创建** | 定义产品名称、品类、通讯协议、开发方式 |
| **产品认证方式** | 一型一密 / 一机一密 / ID²认证 |
| **产品状态** | 开发中 / 已发布 / 已下架 |
| **标签管理** | 支持产品标签，最多100个标签 |

### 2.2 物模型（TSL）

#### 2.2.1 物模型三要素

| 类型 | 说明 | 示例 |
|------|------|------|
| **属性（Property）** | 描述设备运行时状态，支持读写和只读 | 开关状态、温度值、亮度等级 |
| **服务（Service）** | 设备可供外部调用的指令，可含输入/输出参数 | 重启设备、设置温度、执行烘焙 |
| **事件（Event）** | 设备主动上报的信息，用于告警/通知 | 温度超限、设备故障、有人经过 |

#### 2.2.2 属性详细规范

| 参数 | 说明 |
|------|------|
| identifier | 属性唯一标识符（英文） |
| name | 属性显示名称 |
| required | 是否必需属性 |
| type | 数据类型：string/int/float/bool/enums |
| unit | 单位 |
| accessMode | 访问模式：read/write/read_write |
| defaultValue | 默认值 |
| minValue/maxValue | 数值范围（int/float） |
| step | 步进值（int/float） |
| enum | 枚举值列表（enums类型） |

#### 2.2.3 服务详细规范

| 参数 | 说明 |
|------|------|
| identifier | 服务唯一标识符 |
| name | 服务显示名称 |
| method | 服务调用方法：sync/sync_and_notify |
| inputParams | 输入参数列表 |
| outputParams | 输出参数列表 |
| asyncResult | 是否异步返回结果 |

#### 2.2.4 事件详细规范

| 参数 | 说明 |
|------|------|
| identifier | 事件唯一标识符 |
| name | 事件显示名称 |
| level | 事件级别：info/warn/error |
| outputParams | 输出参数列表 |

#### 2.2.5 物模型JSON格式

```json
{

  "profile": {
    "productKey": "a1BxYzKcDeF",

    {
```

### 2.3 设备接入

#### 2.3.1 接入协议

| 协议 | 说明 |
|------|------|
| **MQTT** | 主流协议，支持QoS 0/1/2 |
| **CoAP** | 轻量级协议，适合低功耗设备 |
| **HTTPS** | RESTful接口，适合简单设备 |
| **WebSocket** | 双向通信，适合实时场景 |

#### 2.3.2 认证方式

| 认证方式 | 说明 | 适用场景 |
|---------|------|---------|
| **一型一密** | 同型号设备共用同一密钥 | 低成本设备、测试环境 |
| **一机一密** | 每台设备唯一密钥 | 量产设备、高安全需求 |
| **ID²认证** | 基于国际ID²标准 | 大规模量产、跨国部署 |

#### 2.3.3 设备三元组

```
ProductKey   : 产品唯一标识（如 a1BxYzKcDeF）
DeviceName   : 设备名称（设备唯一标识）
DeviceSecret : 设备密钥（用于生成签名）
```

#### 2.3.4 MQTT连接参数

```
Server     : ${ProductKey}.iot-as-mqtt.cn-shanghai.aliyuncs.com
Port       : 1883 (SSL: 443)
Username   : ${DeviceName}&${ProductKey}
Password   : 使用HmacSHA1(DeviceSecret, clientId+"|publishTimeout=60000|secureMode=2| signmethod=hmacsha1|") 计算
ClientId   : ${DeviceName}|securemode=2,signmethod=hmacsha1,timestamp=1234567890|
```

| 功能 | 说明 |
|------|------|

| **期望数据** | 云端下发期望属性到影子（desired） |

| **状态同步** | 设备与影子双向同步 |

#### 2.6.2 SQL处理示例

```sql
-- 从物模型属性上报Topic提取数据
SELECT
  device_id AS deviceid,
  content.switch AS switch,
  content.temperature AS temperature
FROM `/a1BxYzKcDeF/thing/device/property/post`
WHERE content.temperature > 30

-- 转发目标：消息队列RocketMQ
```

## 四、数据流设计

### 4.1 设备数据上报流

```
设备端 → MQTT Broker → 物联网平台 → 规则引擎 → 云产品/业务系统
                ↓
           设备影子
                ↓
           App/Web控制台
```

### 4.2 设备控制下行流

```
App/Web控制台 → 物联网平台 → 规则引擎 → MQTT Broker → 设备端
                ↓
           设备影子（缓存期望状态）
```

### 4.3 场景联动流

```
设备上报属性 → 规则引擎 → 条件判断 → 执行动作 → 设备控制
     ↓                              ↓
   事件日志                        日志记录
```

### 6.3 数据库表设计建议

```sql
-- 产品表
CREATE TABLE products (
    id BIGSERIAL PRIMARY KEY,
    product_key VARCHAR(64) UNIQUE NOT NULL,
    product_name VARCHAR(128) NOT NULL,
    category_id INTEGER,
    protocol VARCHAR(32),
    auth_type VARCHAR(32),
    tsl_json JSONB,
    status VARCHAR(32),
    tenant_id BIGINT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 设备表
CREATE TABLE devices (
    id BIGSERIAL PRIMARY KEY,
    device_name VARCHAR(128) UNIQUE NOT NULL,
    product_id BIGINT REFERENCES products(id),
    device_secret VARCHAR(256),
    status VARCHAR(32),
    online BOOLEAN DEFAULT FALSE,
    last_online_at TIMESTAMP,
    tags JSONB,
    tenant_id BIGINT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 物模型属性表
CREATE TABLE product_properties (
    id BIGSERIAL PRIMARY KEY,
    product_id BIGINT REFERENCES products(id),
    identifier VARCHAR(128) NOT NULL,
    name VARCHAR(128) NOT NULL,
    type VARCHAR(32) NOT NULL,
    access_mode VARCHAR(32),
    unit VARCHAR(32),
    default_value TEXT,
    min_value DECIMAL,
    max_value DECIMAL,
    step DECIMAL,
    enum_values JSONB,
    required BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP
);

-- 物模型服务表
CREATE TABLE product_services (
    id BIGSERIAL PRIMARY KEY,
    product_id BIGINT REFERENCES products(id),
    identifier VARCHAR(128) NOT NULL,
    name VARCHAR(128) NOT NULL,
    method VARCHAR(32),
    input_params JSONB,
    output_params JSONB,
    async_result BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP
);

-- 物模型事件表
CREATE TABLE product_events (
    id BIGSERIAL PRIMARY KEY,
    product_id BIGINT REFERENCES products(id),
    identifier VARCHAR(128) NOT NULL,
    name VARCHAR(128) NOT NULL,
    level VARCHAR(32),
    output_params JSONB,
    created_at TIMESTAMP
);

-- 设备影子表
CREATE TABLE device_shadows (
    id BIGSERIAL PRIMARY KEY,
    device_id BIGINT REFERENCES devices(id),
    reported JSONB,
    desired JSONB,
    version BIGINT DEFAULT 1,
    updated_at TIMESTAMP
);

-- 规则引擎表
CREATE TABLE rules (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(128) NOT NULL,
    description TEXT,
    sql_expression TEXT NOT NULL,
    source_topic VARCHAR(256),
    actions JSONB,
    status VARCHAR(32),
    tenant_id BIGINT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 场景联动表
CREATE TABLE scenes (
    id BIGSERIAL PRIMARY KEY,
    name VARCHAR(128) NOT NULL,
    description TEXT,
    trigger_config JSONB,
    action_config JSONB,
    status VARCHAR(32),
    tenant_id BIGINT,
    created_at TIMESTAMP,
    updated_at TIMESTAMP
);

-- 遥测数据表（分区表）
CREATE TABLE telemetry (
    id BIGSERIAL,
    device_id BIGINT REFERENCES devices(id),
    property_identifier VARCHAR(128),
    value_float DECIMAL,
    value_int BIGINT,
    value_string TEXT,
    value_bool BOOLEAN,
    timestamp TIMESTAMP NOT NULL,
    PRIMARY KEY (id, timestamp)
) PARTITION BY RANGE (timestamp);
```

1. **完整的生命周期管理**：从产品开发到设备量产到运营维护
